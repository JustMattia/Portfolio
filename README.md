## Pubblicare su GitHub Pages
1. Crea un repository e carica tutto il contenuto di questa cartella nella root (`index.html`, `assets/`, `.nojekyll`).
2. Vai su Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)` → Save.
3. Dopo qualche minuto il sito è online su `https://<tuo-utente>.github.io/<repo>/`.
   (Se chiami il repo `<tuo-utente>.github.io` il sito sta direttamente su `https://<tuo-utente>.github.io/`.)
